VIKASH MART - FLASK E-COMMERCE STARTER

1. Install Python 3.
2. Open this folder in VS Code.
3. Open Terminal.
4. Run:
   pip install -r requirements.txt
5. Run:
   python app.py
6. Open:
   http://127.0.0.1:5000

The database shop.db is created automatically on first run.

IMPORTANT:
- This is a starter/demo store.
- Do not accept real payments yet.
- Before production, add authentication, CSRF protection, server-side validation,
  secure secret management, payment gateway, order management, HTTPS, backups,
  proper image storage, email/SMS notifications, and an admin panel.
